# dsh-agent-catalog：智能体定义中心

负责已审核 Agent Definition（智能体定义）的不可变发布、租户授权和默认版本查询。
在线 HTTP（超文本传输协议）进程默认只读。可显式配置独立工作台写池，让租户管理员从已授权模板受限派生；普通成员仍不能发布。完整模板、授权与默认值仍由运维管理，详见[工作台说明](../docs/agent-studio.zh-CN.md)。

## 定义与授权

定义包含标识、版本、名称、说明、系统提示词、模型配置、工具白名单、
已审核 Skill（技能）的内联指令与执行预算。远程工具仅允许 `workspace.list`（列文件）、
`workspace.read`（读文件）、`workspace.write`（写文件）及有明确知识源授权的 `knowledge.search`（知识检索）。未知字段、Shell（命令解释器）、
MCP（模型上下文协议）服务器配置、远程技能下载地址和重复工具都会被拒绝。

这里只保存、校验配置，不执行模型、工具或技能。当前 Workflow（工作流）的批准顺序模板与条件跳过交给 DSH 原生引擎，人工审批和失败补偿尚未实现。执行器实际落实白名单与预算，不能只依赖提示词。

技能交给 DSH 原生注册表和加载器，不再把全部正文拼入系统提示词。可选原生名称、路由描述和模型／用户调用策略，重复名称和标识拒绝发布；技能不能增加远程工具权限。示例及旧定义升级注意事项见 [原生技能说明](../docs/native-skills.zh-CN.md)。

PostgreSQL（关系型数据库）使用独立的 `catalog` Schema（数据库模式），不访问其他服务的表。
`definitions`（定义版本表）按标识和版本唯一；同版本相同内容允许重复发布，不同内容返回版本冲突。
数据库触发器同时拒绝更新和删除已发布版本；修改必须增加版本号。
`tenant_definitions`（租户授权表）明确授权，每个租户最多 100 个版本、最多一个默认版本。
权限授予整个租户，目前不区分同一租户内的用户和角色。

在线账号 `catalog_reader`（定义中心只读账号）只能读取本模式；发布及迁移使用 `catalog`（管理账号）。
不启用工作台时无需给在线服务管理连接串。启用时应另外提供最小权限写账号；本地辅助脚本暂用本模式管理账号。定义不能包含模型密钥、口令或不应向租户成员展示的秘密。

## 接口与发布

内部 JWT（JSON 网络令牌）仅接受前端聚合服务和会话服务，两条调用边使用不同密钥。

| 路径 | 用途 |
| --- | --- |
| `GET /internal/v1/definitions` | 当前租户已授权定义摘要 |
| `GET /internal/v1/definitions/default` | 当前租户默认定义，供创建会话使用 |
| `GET /internal/v1/definitions/:id/versions/:version` | 已授权的精确版本 |

默认版本切换只影响新会话。Chat（会话服务）保存精确版本；同一幂等键重试不会切换版本，
定义中心短暂故障也不影响已经成功创建的请求重放。

管理员在根目录构建后，用管理账号设置 `DATABASE_URL`（数据库连接串）：

```powershell
npm run migrate -w @dsh-agent/catalog
npm run publish -w @dsh-agent/catalog -- --file definitions/document-agent.v1.json --tenant local-dev --default
```

`--file`（定义文件）相对于服务工作目录；`--tenant`（授权租户）必须是身份系统发放的真实租户标识；
`--default`（设为默认）只在明确切换默认版本时使用。示例模型名来自当前上游示例，
真正执行前须确认模型账号支持该名称；此阶段没有调用模型或消耗模型额度。

| 在线环境变量 | 含义 |
| --- | --- |
| `DATABASE_URL` | 只读账号连接串 |
| `CATALOG_STUDIO_DATABASE_URL` | 可选工作台写池；未配置则关闭发布，需要第 2 版迁移 |
| `API_CATALOG_SECRET`、`CHAT_CATALOG_SECRET` | 不同的服务签名密钥，各不少于 32 字节 |
| `RUN_CONTROL_CATALOG_SECRET` | 运行控制读取精确授权版本的独立密钥，与上面两项不同 |
| `PORT` | 端口，默认 8080 |

已实现工作台受限发布页面；发布审批、网页授权撤销、模型计费管理和独立技能市场尚未实现。
# 租户授权撤销补充

管理员可使用本服务管理数据库账号执行：

```powershell
node dist/revoke.js --tenant tenant-a --id document-agent --version 1
```

三个参数分别为租户、定义标识和版本。只删除该租户对指定版本的授权，不删除不可变定义，也不影响其他租户。
重复撤销安全；重新发布相同定义可恢复授权。撤销默认版本后不会自动选取另一个默认值，新建会话可能返回未找到定义。
已冻结的运行输入不会被追溯撤销；若需停止当前执行，应另外取消运行。在线只读账号不能执行此命令。

## 工作流定义

可选 `workflow.steps`（工作流步骤）支持最多八个顺序步骤及字面文本条件跳过。
发布时验证唯一标识、第一步无条件、步骤预算总和与工具子集；旧定义没有此字段时保持单步执行。
沿用不可变版本及租户授权，无新增在线管理写接口或数据库迁移。
示例、发布命令及语义见 [工作流说明](../docs/workflow.zh-CN.md)；新示例未自动设为任何租户的默认定义。
