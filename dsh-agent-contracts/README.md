# dsh-agent-contracts：公共协议

本包提供请求、响应、分页、错误和事件数据结构。使用 Zod（运行时结构校验库）定义协议，
通过 TypeScript 类型与 OpenAPI 3.1（开放接口描述规范）对外共享。

不包含数据库、认证算法、服务调用或 DSH 实现。其他服务只通过
`@dsh-agent/contracts` 包名导入，不能跨目录导入业务代码。

在工作区根目录运行 `npm run build -w @dsh-agent/contracts` 会生成编译产物、
`openapi.json`（公共接口描述）和 `execution-openapi.json`（内部执行接口描述）。
后者包含工作进程租约、输入快照和助手投影协议，不能添加到公网网关或前端代理。
还包含运行工作区能力、工作区到运行控制的在线授权查询及三种受限工具的输入/输出协议。
输入结构默认拒绝额外字段，前端不能提交 `uid`、`tenantId`、工具列表或权限模式。

公共事件采用字段白名单。只投影已定义的消息标识、运行标识和文本增量，删除未知字段。
这能防止任意内部事件结构被直接转发，但不是对自然语言内容中敏感信息的全面识别。

事件类型带 `v1` 版本后缀；兼容性变更需明确版本。`eventId`（事件标识）用于客户端去重；
SSE 的 `Last-Event-ID`（最后事件标识）使用 `sessionId:streamSequence`
（会话标识:消息流序号）恢复读取位置。

消息角色支持 `user`（用户）和 `assistant`（助手）。助手消息附带
`runId`（运行标识）与 `replyToMessageId`（回复目标消息标识），前端应兼容新增角色和字段。
