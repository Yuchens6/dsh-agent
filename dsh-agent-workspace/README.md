# dsh-agent-workspace：工作区文件服务

用户文件与工作区归属的唯一数据所有者。元数据使用 PostgreSQL（关系型数据库）的
`workspace` Schema（数据库模式），正文使用 S3（简单存储服务）兼容对象存储。
其他服务通过 HTTP（超文本传输协议）访问，不直接读表或挂载存储目录。

## 能力和边界

- 按 `tenantId + uid`（租户标识与用户标识）唯一分配工作区；`directoryName`（目录展示名）为用户标识。
- 工作区与文件版本采用 UUIDv7（第七版通用唯一标识符），存储键仅由工作区标识和版本标识组成。
- 支持文本文件列表、读取、新建、覆盖、删除；正文使用 UTF-8（统一字符编码），单文件最多 64 KiB（千二进制字节）。
- 当前文件总量最多 16 MiB（兆二进制字节）、1024 个文件；待提交上传最多 16 个、1 MiB。
- 所有访问均验证租户及所有者；他人资源与不存在资源统一返回 404。
- 路径必须是 NFC（规范组合形式）的有效 Unicode（统一码）相对路径，不接受绝对路径、盘符、反斜线、点段、百分号和控制字符。
- 目录只是虚拟前缀，不存在符号链接、硬链接或宿主机路径解析；文件与目录前缀不能重名。
- `expectedVersion`（预期版本）为空值时仅允许新建；覆盖与删除必须匹配读取时的版本，否则返回 409。
- 删除后重建会获得全新版本，避免 ABA（值变化后回到原值导致误判）问题。

这是“逻辑目录名为用户标识”的对象存储实现，不是所有执行器共享的服务器目录。
当前不支持任意二进制、大文件、空目录、重命名、历史版本下载或恢复。

## 权限与接口

| 调用方 | 允许范围 |
| --- | --- |
| API（前端聚合服务） | 当前主体的工作区与文件操作 |
| Chat（会话服务） | 仅分配/获取该主体的唯一工作区，用于创建会话 |
| Runtime DSH（执行服务） | 仅持运行能力令牌访问受限工具接口；执行进程本身尚未实现 |
| 浏览器身份令牌 | 不接受，必须通过前端聚合服务 |

内部 JWT（JSON 网络令牌）按调用服务分别使用密钥，验证签名、签发者、受众与有效期。
不得把前端聚合服务的签名密钥交给模型或执行器。执行接口采用独立的短期
Capability（能力令牌），通过在线授权把运行、执行节点、租约与尝试编号解析为绑定工作区及允许的工具。

内部路径前缀为 `/internal/v1`，前端聚合服务代理的公共前缀为 `/api/v1`。

| 方法和路径 | 用途 |
| --- | --- |
| `POST /workspaces/ensure` | 不带正文，幂等获取当前用户工作区 |
| `GET /workspaces/:workspaceId` | 容量与文件数 |
| `GET /workspaces/:workspaceId/files` | 路径排序分页；`prefix` 为目录前缀，`after` 为路径游标，`limit` 最大 100 |
| `GET /workspaces/:workspaceId/file?path=notes/a.txt` | 内容与版本 |
| `PUT /workspaces/:workspaceId/file` | 正文包含 `path`（路径）、`content`（内容）、`expectedVersion`（预期版本） |
| `DELETE /workspaces/:workspaceId/file?path=notes/a.txt&expectedVersion=...` | 按版本删除 |

空前缀应省略参数；非空前缀不带末尾斜线，列表返回该目录下所有层级的文件。
写入不自动重试：网络结果不确定时重新读取并核对版本/内容，不得自动获取最新版本覆盖。

## 执行器受限工具

工作区服务新增 `POST /execution/v1/tools`（第一版执行工具接口），不经过前端聚合服务或公网网关。
请求使用 `Authorization: Bearer`（持有者授权）携带运行控制签发的短期令牌，正文只包含
`tool`（工具名称）与 `arguments`（参数）。不接受用户、租户、工作区标识或任意远程地址。

| 工具 | 参数 | 返回 |
| --- | --- | --- |
| `workspace.list`（列目录） | 可选目录前缀、路径游标、页大小 | 文件元数据页 |
| `workspace.read`（读文本） | 虚拟相对路径 | 内容与版本 |
| `workspace.write`（条件写文本） | 路径、内容、预期版本 | 已提交文件元数据 |

没有删除、命令执行、宿主路径访问、任意网络请求或 MCP（模型上下文协议）入口。
只有运行快照中的工具名单允许调用；前端文件管理权限不会自动成为执行器权限。
返回格式为 `tool` 与 `result`（结果），错误继续使用标准错误结构，不包含内部凭据或对象键。

流程：本地验证能力签名与最长 30 秒有效期 → 以独立服务凭据向 Run Control（运行控制服务）
查询实时授权 → 从响应取得固定用户/工作区 → 由本服务再次检查资源归属并执行。
能力只携带运行租约引用，没有允许模型修改的主体字段；租约续期不会延长已签发令牌。
工作区不缓存肯定授权，运行控制不可达、回复不匹配或过大、签名失败时一律拒绝操作。
授权请求限时 2 秒、响应最多 16 KiB（千二进制字节）、不跟随重定向。

写入在预留上传票据前、上传完成且切换文件版本前分别重新授权。第二次失败时，
原文件仍可见，上传的新对象保持暂存，由现有回收器清理；不会因为取消而删除原文件。
读取在获取对象前、返回正文前重新授权；列表也在返回结果前重新授权。
运行状态变为取消、成功、失败，或租约/截止时间失效后，后续授权均被拒绝。

**这不是跨服务原子撤销。** 最终授权检查与本地数据库提交之间仍有窗口，
在取消完成前已经获得最终授权的操作，可能在取消响应之后完成；已返回的数据也不能撤回。
取消不回滚已提交文件。当前没有跨服务提交屏障或在途操作清空确认协议，
若业务要求“取消返回即绝无后续提交”，还需引入持久操作票据与撤销确认协议，不能仅靠短期令牌声称实现。
执行器不能把 HTTP（超文本传输协议）超时当作写入未发生，应停止盲目重试并核对版本。

隔离保证依赖受限工具组合：不得为模型另开默认本地文件、Bash（命令解释器）或插件入口，
不能把长期服务密钥、对象存储密钥或全部用户目录交给执行器。
能力是可转交的持有者凭据，并非硬件绑定执行节点；持有者只能在该运行授权范围及有效期内使用，必须避免记录或泄漏。

## 一致性与回收

先在数据库内锁定工作区、检查版本及额度、保存上传票据；再上传不可覆盖的对象；
上传成功后重新锁定并检查版本，原子切换当前文件引用、容量和对象状态。
版本竞争失败不覆盖新内容；未提交对象仍有数据库记录。覆盖和删除把旧对象标记为待回收。

GC（垃圾回收）清理超过一小时的未提交对象和被替换对象，每次最多 1000 个。
先删除对象，成功后再删除记录并释放上传预留额度；失败可重试。
读取、提交和回收使用相同的工作区行锁顺序。对象请求限时五秒；同一工作区读取会串行，
这是当前为保证读取与回收一致性作出的性能取舍，尚未进行千用户负载验证。

```powershell
npm run migrate -w @dsh-agent/workspace
npm start -w @dsh-agent/workspace
npm run gc -w @dsh-agent/workspace
```

| 环境变量 | 含义 |
| --- | --- |
| `DATABASE_URL` | 专属数据库连接串 |
| `API_WORKSPACE_SECRET`、`CHAT_WORKSPACE_SECRET` | 不同的服务签名密钥，各不少于 32 字节 |
| `RUN_CONTROL_WORKSPACE_SECRET` | 验证运行控制签发的短期能力，执行器不能持有此长期密钥 |
| `WORKSPACE_RUN_CONTROL_SECRET` | 工作区向运行控制查询授权的独立签名密钥 |
| `RUN_CONTROL_URL` | 运行控制服务的 HTTP/HTTPS（明文/加密超文本传输协议）原点地址，不含路径 |
| `S3_ENDPOINT`、`S3_REGION`、`S3_BUCKET` | 对象存储端点、区域、桶名 |
| `S3_ACCESS_KEY`、`S3_SECRET_KEY` | 仅本服务持有的桶访问凭据 |
| `PORT` | 端口，默认 8080 |

桶必须预先存在、禁止公开访问，并支持 `If-None-Match: *`（仅当对象不存在时写入）。
采用未启用版本管理的专用桶，或为桶历史版本另配保留/清理政策：当前回收器不枚举桶历史版本。
服务账号只授予本桶对象读写删除和就绪检查所需权限，不授予桶管理权限。
生产要求 HTTPS（加密超文本传输协议），不要通过修改运行环境绕过检查。

数据库和对象存储须协调备份/恢复；回收窗口需满足业务恢复要求。
逻辑文件额度不是物理存储或请求费用上限，频繁覆盖会产生短期旧对象。
用户速率、全局费用、审计和告警需要后续 Quota（配额服务）与 Audit（审计服务）补齐。
新增权限链路没有增加数据库迁移；在线进程必须配置上述两把独立密钥及运行控制地址，四把密钥必须互不相同。
文件管理的就绪检查不依赖运行控制在线；只有执行器工具在授权服务故障时失败关闭。
每次工具调用包含多次授权查询，尚未做千用户压力测试；定义级工具调用次数/模型预算仍由后续执行器实现。
## 变更审计与指标（第二版迁移）

工作区首次创建、文件成功写入及删除在所属业务事务内保存审计，包含工作区和文件版本标识，不含路径与正文。
上传已发生但审计本地写入失败时，新对象保留为暂存状态，不发布为可见版本，由既有回收流程处理。
网络投递失败保留票据、指数退避；不占用工作区业务行锁，不自动重做文件操作。
目前不记录列举、读取、失败或拒绝请求，不能宣称完整访问审计。
新增 `AUDIT_URL`（审计地址）、`WORKSPACE_AUDIT_SECRET`（审计写入密钥）及 `WORKSPACE_METRICS_SECRET`（指标密钥）。
`GET /metrics`（读取内部指标）提供审计、暂存对象和待回收对象计数，详见 [监控接入](../dsh-agent-deploy/monitoring/README.md)。
