# 青禾教师登录与账号系统原型 V1

这是登录与账号系统 PRD V1.0 对应的前端交互原型，用于产品评审、联调前验收和交付演示。

## 运行方式

本目录是静态页面原型，需要通过 HTTP 静态服务器打开，不能只依赖直接双击 `index.html`。

在本目录执行以下任一方式：

```powershell
python -m http.server 3000
```

然后访问 <http://localhost:3000/>。

也可以使用 Node.js 的任意静态文件服务器启动本目录。

## 演示数据

- 测试邀请码：`12345`
- 测试邮箱验证码：`123456`

以上数据仅用于原型演示，不能用于生产环境。

## 当前范围与限制

- `index.html` 与 `auth-v1.js` 必须放在同一目录。
- 当前登录、注册、重置密码、会话、邀请码和验证码行为由浏览器本地存储模拟。
- 原型会使用 `localStorage` 和 `sessionStorage` 保存演示状态；正式环境不得采用该方式保存生产凭据或生产会话。
- 当前未接入 `dsh-agent-iam`、BFF、Keycloak 或正式账号 API。
- 生产实现仍需按 PRD 完成服务端校验、邀请码并发控制、验证码限流、CSRF、防重放、HttpOnly Cookie 会话、审计和幂等注册等能力。

本目录内容不代表生产账号系统已经完成。
