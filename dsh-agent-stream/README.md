# dsh-agent-stream：事件流服务

本服务监听 8080 端口，提供 SSE（Server-Sent Events，服务器发送事件）：

```text
GET /events/v1/sessions/{sessionId}
Authorization: Bearer <IAM 访问令牌>
X-Session-Capability: <会话服务签发的短期订阅凭证>
Last-Event-ID: <会话标识>:<消息流序号>
```

先调用 API 的订阅接口，再通过支持自定义请求头的 `fetch`（浏览器请求接口）读取事件流。
不把令牌放入查询参数。原生 `EventSource`（浏览器事件源）不适用于这一请求头认证方式。

每次连接验证两份凭证，确认会话、租户、用户和订阅权限全部匹配。
连接在 IAM 凭证或能力令牌中较早的到期时间关闭，最长 60 秒。
客户端重新申请能力令牌，并携带最近游标重连；这限制了权限撤销后的存量连接生存时间。

NATS JetStream（持久化消息流）按会话主题创建临时有序消费者。
历史重放与实时读取使用同一个消费者，避免切换时遗漏事件；按小批次拉取，
HTTP 写缓冲区满时暂停读取，5 秒无法恢复则断开慢消费者。
每 20 秒发送心跳；每实例最多 1000 个连接，包括正在建立订阅的请求。
这些是开发默认值，生产需按负载与网关限流一起调整，不能将其视为压测容量结论。

游标跨会话或格式错误返回 400；历史保留窗口之外的游标返回 409 `CURSOR_EXPIRED`
（游标已过期），客户端应重新读取历史后订阅，不能静默当作完整续传。
事件再次核对租户、用户和会话，并通过协议白名单过滤额外字段。

依赖配置包括 `IAM_ISSUER`（身份签发者）、`IAM_JWKS_URL`（验证密钥集地址）、
`IAM_AUDIENCE`（身份受众）、`CHAT_CAPABILITY_SECRET`（能力验证密钥）以及
`NATS_URL`、`NATS_TOKEN`（消息代理地址与凭据）。

当前提供 SSE，不提供 WebSocket（网页双向通信）。不访问业务数据库，也不连接 DSH Worker
（执行工作节点）。生产消息代理必须通过 ACL（访问控制列表）禁止本服务发布业务事件。
