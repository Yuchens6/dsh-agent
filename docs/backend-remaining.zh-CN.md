# 非前端后续实现清单

第十九阶段已实现可配置 PostgreSQL（关系型数据库）全文、结构化、纯图谱与无向量混合检索，保留 LightRAG 后端；纯 PostgreSQL 方案不需要部署向量模型。已提供独立只读账号、迁移与审核语料导入方案，见 [无向量检索手册](nonvector-rag.zh-CN.md)。真实资料入库、分词/图谱质量、业务数据同步、源管理、逐文档权限、持久检索审计与生产容量仍待验收或实现。

第十八阶段接入 DSH 原生技能注册表与加载器，移除平台全部技能正文拼接；原生技能与远程工具共享预算，支持模型按需及用户显式调用。
本轮没有完成跨轮会话恢复；后续复用原生持久化协调器，先落实租约、成功提交与消息游标边界。见 [原生技能与能力复用说明](native-skills.zh-CN.md)。

第十七阶段移除平台固定轮数／总字符上下文裁剪，使用 DSH 原生词元估算与压缩。
目前每次运行导入完整 Chat 文本记录；下一步是原生日志、工具事件和压缩检查点的跨轮持久化与增量恢复。见 [上下文说明](native-context.zh-CN.md)。

第十六阶段工作流已改用 DSH 原生引擎，平台只调用执行并接收状态，不实现业务流程推进。
当前开放顺序预置模板；后续复杂流程应继续扩展原生模板与必要的平台权限/计量适配，不在运行控制服务重建编排引擎。见 [工作流说明](workflow.zh-CN.md)。

第十四阶段已增加 LightRAG 图谱/向量检索桥接和运行授权，见 [接入说明](lightrag-integration.zh-CN.md)。
若使用 LightRAG，仍需真实上游、向量模型、文档入库与检索质量验收；第十九阶段已提供无需这些模型依赖的另一个后端。知识源在线管理、文档级权限、持久检索审计、索引/向量费用计量均未完成。

第十三阶段已交付实时状态／模型正文预览／最终快照，详见 [实时反馈说明](realtime-feedback.zh-CN.md)。
尚需真实模型与生产数据库验收、分布式任务唤醒、长连接容量及全链路队列容量治理；不能宣称一万同时对话已验收。

本清单区分“已交付基础功能”和“生产完整能力”，不把前端未开发作为后端缺口的理由。
