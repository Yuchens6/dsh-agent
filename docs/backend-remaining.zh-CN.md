# 非前端后续实现清单

本清单区分“已交付基础功能”和“生产完整能力”，不把前端未开发作为后端缺口的理由。

| 模块 | 本轮已交付 | 尚未完成及实施约束 |
| --- | --- | --- |
| Quota（配额与积分） | 并发与保守预算、逐次用量、公司硬分配员工积分、可配置人民币计价与兑换比例、快照冻结、幂等扣费、本人余额/流水、受控管理命令 | 供应商账单对账、支付充值、退款/回收、管理员授权接口、逐调用费用上限、月度套餐、异常冻结巡检、缺失计量补录；未知不得当零 |
| Audit（审计） | 运行生命周期、会话及文件变更事件、独立生产者认证、事务发件箱重传、本人查询、追加写保护 | 身份/读取/拒绝事件接入、管理员检索导出、分区归档；不追溯伪造历史事件 |
| Chat（会话） | 标题/归档、版本冲突、跨副本新消息窗口限流、未投递积压门禁、有界连接等待及并行发布 | 全链路队列容量、删除及恢复协议；不能只删会话表而留下运行、订阅和对象引用 |
| Catalog（定义中心） | 版本授权撤销/恢复、在线只读；顺序工作流定义、步骤预算及工具子集校验 | 审批流程、管理员接口、复杂工作流定义；当前不加载用户可执行插件 |
| Run Control（运行控制） | 配额前置、并行支撑/回答投递、低负载与等待老化调度、公司/用户并发；持久工作流 | 消费分片、全局锁扩展、完整配额感知排队、并行图编排、审批、恢复/补偿、人工重试；重试需新预留和副作用确认 |
| Runtime DSH（DSH 执行服务） | 配额门禁、受限工具与审核技能、逐次用量、每步子进程、可配置 1–16 执行槽，确认失败不重跑 | 供应商速率控制、缺失计量补偿、逐字输出、复杂工作流及恢复；任意代码需要独立安全沙箱 |
| Workspace（工作区） | 文本文件和运行绑定隔离沿用已验收实现 | 大文件/二进制、保留历史和回滚、强撤销；新增在途操作追踪与终止确认，不能只缩短令牌有效期 |
| IAM（身份与访问管理） | 既有 Keycloak（身份管理平台）配置和身份令牌校验 | 多租户成员管理、邀请/移除、角色授权和切换租户协议；身份声明不能来源于用户可编辑属性 |
| 运维安全 | 服务容器、角色、迁移、网络策略、默认关闭的运行器；会话/工作区/运行控制鉴权指标端点及告警模板 | 监控服务器和告警接收器部署验收、其余服务指标、链路追踪、全局用户限流、内部 mTLS（双向传输层安全）、密钥轮换、灾难恢复 |
| 验收 | 本机数据库兼容引擎、真实消息代理、模拟模型；1000 用户接收基线与 10000 用户有限在途过载实验 | 256 路建连拒绝问题、原生 PostgreSQL（关系型数据库）多连接竞争、真实对象存储/模型、容器/集群及全链路容量验收 |

以上项目尚未全部实现，不能据此宣称整个非前端系统已生产完工。
顺序工作流基础版已落地。建议下一批完善全局请求限流与租户成员管理；环境具备后验收真实模型、监控及压力容量，再扩展审批、恢复和跨服务删除，
避免让新功能绕过既有租约、配额和所有权边界。
